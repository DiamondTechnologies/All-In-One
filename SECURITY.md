# Security Policy

I take the security of **All In One** seriously. As a solo maintainer, I appreciate the community's help in responsibly discovering and reporting vulnerabilities.

---

## Supported Versions

Security updates are only provided for the latest stable release:

| Version | Supported |
| :--- | :---: |
| **Latest (1.x)** | ✅ |

> **Note:** Since this app uses **.NET 10** and **WinUI 3 (MSIX Packaged)**, its baseline security also depends on an updated Windows OS environment.

---

## Reporting a Vulnerability

**Please DO NOT open public GitHub Issues for security vulnerabilities.**

As a single maintainer, private reporting helps me fix issues before they are publicly known.

1. Go to the **[Security](../../security)** tab of this repository.
2. Click **Report a vulnerability** to open a private draft.
3. Include clear details:
   - App version & Windows version (e.g., Windows 11 23H2).
   - Step-by-step reproduction / Proof of Concept (PoC).
   - Potential impact (e.g., capability bypass, insecure file access).

*If GitHub Private Reporting is unavailable, reach out directly via email: **connect.diamond.tech@yandex.ru***

---

## Expected Response Time

* **Acknowledgement:** I will review your report within **3–5 business days**.
* **Fix & Release:** As this is an open-source side project, fix timelines depend on my availability and issue severity. Critical flaws will be prioritized.
